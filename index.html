CI / webhook

Call the API from GitHub Actions, GitLab CI, or any PR bot. High-risk responses can fail the job or open an alert.

curl -s -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"loc":2400,"cyclomatic_complexity":32,"code_churn":48,"review_coverage":0.4,"test_coverage":0.35,"team_experience":0.45,"language":"Java","module_type":"Core"}'

Batch: POST /predict/batch with {"items":[ {...}, ... ]}. Health: GET /health.
